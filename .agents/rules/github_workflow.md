# GitHub Workflow Rules

Pour ce projet, les règles suivantes s'appliquent systématiquement à chaque modification ou conversation :

1. **Branche Principale pour le Web** : Pousser (push) systématiquement toutes les corrections et modifications sur la branche `gh-pages` du dépôt GitHub. 
2. **Déploiement Web** : Le site web se met à jour uniquement depuis cette branche `gh-pages`, c'est donc la branche sur laquelle il faut travailler et pousser les changements principalement.
